# Data Directory

This directory is intended for the dataset files used in the Arabic Text Processing and Classification project. 

Due to file size limits and privacy/copyright reasons, the datasets are not included in the repository.

## Required Files
To run the pipeline successfully, please place the following files in this directory:
1. `News_train.xlsx`
2. `News_test.xlsx`

## Schema
The expected schema for the excel files is:
- **`News`**: The text of the Arabic news headline.
- **`Type`**: The target label/category of the news.
